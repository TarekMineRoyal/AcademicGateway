        S->>FE: Select Professor P & request supervision
        activate FE
        FE->>API: POST /api/project-instances/{projectInstanceId}/supervision-requests
        activate API
        API->>CQRS: Dispatch SubmitSupervisionRequestCommand
        activate CQRS
        CQRS->>DB: Create SupervisionRequest (Status = Pending)

        Note over P, DB: Professor Queue Fetch Flow
        P->>FE: Open pending requests queue
        activate FE
        FE->>API: GET /api/supervision-requests/pending/{professorId}
        activate API
        API->>CQRS: Dispatch GetPendingSupervisionRequestsQuery
        activate CQRS
        CQRS->>DB: Query SupervisionRequests (Status = Pending)
        activate DB
        DB-->>CQRS: Pending requests retrieved
        deactivate DB
        CQRS-->>API: Return PaginatedResult<PendingSupervisionRequestDto>
        deactivate CQRS
        API-->>FE: 200 OK
        deactivate API
        FE-->>P: Render pending requests queue
        deactivate FE
    end

        CQRS->>DB: Update ProjectInstance (Status = Active) & SupervisionRequests (Status = Rejected)
        activate DB

        deactivate DB

        deactivate CQRS
